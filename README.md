# 箱庭仓库

一个中文像素风推箱子小游戏，共有六个手工关卡。操纵戴红帽子的搬运工，把木箱推到绿色目标点上。所有图形均由 Canvas 绘制，可以离线游玩。

## 启动

下载或复制整个项目，保留各文件的相对位置，然后在现代浏览器中打开 [index.html](./index.html) 即可。游戏使用原生 HTML、CSS 和 JavaScript，无需安装依赖或构建。

如果想通过本地服务器游玩，可在装有 Python 3 的电脑上进入项目目录，运行以下命令，再用浏览器访问 <http://127.0.0.1:8000>。按 Ctrl+C 停止服务。

```sh
python -m http.server 8000 --bind 127.0.0.1
```

## 玩法与操作

每次移动一格。前方有木箱时，只要箱子后面有一格空地，就可以把箱子向前推。搬运工不能拉箱子，也不能同时推动两个箱子。木箱到达目标点后会变绿并显示勾号，仍可继续推动。所有木箱同时归位即可通关。

| 操作 | 控制方式 |
| --- | --- |
| 移动 | 方向键或 WASD，也可点击页面方向按钮 |
| 撤销一步 | Z 或「撤销」，可连续使用 |
| 重开本关 | R 或「重开」 |
| 选择关卡 | 右上角的关卡菜单 |
| 继续挑战 | 通关后点击「进入下一关」 |

只有成功移动才计步，推箱也算一步。撤销会还原上一步的位置和步数。箱子被推入死角时，可以用撤销找回转向的空间。

## 关卡与记录

六关依次为初入仓库、并排入库、转角货架、三箱同行、窄巷调度和最后一班，可自由选择。切换关卡或刷新页面会重新开始棋局。游戏用浏览器的 `localStorage` 保存每关通关时的最低步数，菜单中的 ✓ 表示该关已完成。浏览器限制本地存储时，成绩仅在当前页面有效。
